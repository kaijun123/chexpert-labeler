## FYP Guide

This repo is used to obtain the pathology labelers from the generated output.

Additional code at `classification.sh` and `classification_jobscript.sh` has been written to automate this process.
To use the script, copy all the relevant csv files containing the outputs into the root directory of this repo. 
The script will check for all csv files in the root directory level. The output will be saved in the `output` directory
